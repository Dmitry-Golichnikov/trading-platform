# Быстрый старт с GUI

Руководство по началу работы с desktop GUI приложением.

## Установка

### 1. Установить GUI зависимости

```bash
# Вариант 1: Через pyproject.toml (рекомендуется)
pip install -e ".[gui]"

# Вариант 2: Напрямую
pip install PyQt6 pyqtgraph qdarkstyle qt-material

# Вариант 3: Через requirements
pip install -r requirements/gui.txt
```

### 2. Проверить установку

```bash
python -c "import PyQt6; import pyqtgraph; print('OK')"
```

## Запуск

```bash
# Способ 1: Через entry point (если пакет установлен)
trading-gui

# Способ 2: Через launcher script
python src/interfaces/gui/scripts/run_gui.py

# Способ 3: Напрямую
python -m src.interfaces.gui.desktop.main
```

## Основные возможности

### 📊 Работа с данными

1. Откройте вкладку **"📊 Данные"**
2. Нажмите **"📂 Загрузить из файла"**
3. Выберите CSV или Parquet файл с OHLCV данными
4. Введите имя датасета
5. Просмотрите график или таблицу

**Требования к файлу:**
- Обязательные колонки: `timestamp`, `open`, `high`, `low`, `close`, `volume`
- Формат timestamp: ISO8601 или unix timestamp

### 🔧 Генерация признаков

1. Откройте вкладку **"🔧 Признаки"**
2. Выберите индикаторы из древовидного списка
3. Нажмите **"➕ Добавить в конфиг"**
4. Настройте параметры в YAML редакторе
5. Нажмите **"▶️ Сгенерировать признаки"**

**Пример конфига:**

```yaml
features:
  - type: SMA
    window: 20
  - type: RSI
    window: 14
  - type: MACD
    fast_period: 12
    slow_period: 26
    signal_period: 9
```

### 🎯 Разметка данных

1. Откройте вкладку **"🎯 Разметка"**
2. Выберите метод разметки (Triple Barrier / Horizon / Regression)
3. Настройте параметры:
   - Take Profit: 2% (0.02)
   - Stop Loss: 2% (0.02)
   - Time Barrier: 50 баров
4. Нажмите **"▶️ Применить разметку"**
5. Просмотрите результаты:
   - График с метками Long/Short
   - Таблица меток
   - Статистика классов

### 🤖 Обучение модели

1. Откройте вкладку **"🤖 Обучение"**
2. Выберите:
   - Модель (LightGBM, XGBoost, LSTM, etc)
   - Датасет
   - Конфигурацию признаков
   - Метод разметки
3. Настройте гиперпараметры:
   - Epochs: 10
   - Learning Rate: 0.001
   - Batch Size: 64
4. Нажмите **"▶️ Начать обучение"**
5. Наблюдайте real-time графики loss и accuracy

**Результаты:**
- Loss curves (train/val)
- Accuracy curves (train/val)
- Логи обучения по эпохам

### 📈 Бэктестинг

1. Откройте вкладку **"📈 Бэктестинг"**
2. Выберите обученную модель и датасет
3. Настройте параметры стратегии:
   - Порог входа: 0.5
   - Take Profit: 3% (0.03)
   - Stop Loss: 2% (0.02)
   - Комиссия: 0.1% (0.001)
4. Нажмите **"▶️ Запустить бэктест"**
5. Просмотрите результаты:
   - Equity Curve vs Buy & Hold
   - Таблица всех сделок
   - Метрики (Sharpe, Sortino, Win Rate, etc)

### 🔬 Комплексные эксперименты

1. Откройте вкладку **"🔬 Эксперименты"**
2. Выберите элементы из списков (множественный выбор):
   - Датасеты
   - Конфигурации признаков
   - Методы разметки
   - Модели
   - Стратегии
3. Включите **"Все комбинации"** для полного перебора
4. Нажмите **"▶️ Запустить эксперименты"**
5. Подождите завершения batch processing
6. Просмотрите сводную таблицу результатов
7. Отфильтруйте прибыльные: **"✨ Только прибыльные"**
8. Экспортируйте: **"📥 Экспорт в CSV"**

## Горячие клавиши

- `Ctrl+O` - Открыть конфигурацию
- `Ctrl+S` - Сохранить конфигурацию
- `Ctrl+Q` - Выход из приложения
- `F1` - Открыть документацию
- `F5` - Обновить (где доступно)

## Темы оформления

Переключение темы через меню:
- **Вид** → **Тёмная тема** (включить/выключить)

По умолчанию используется тёмная тема (qdarkstyle).

## Экспорт данных

Все таблицы поддерживают экспорт:
1. Нажмите **"Экспорт в CSV"**
2. Выберите путь сохранения
3. Файл будет сохранён в формате CSV

## Troubleshooting

### Приложение не запускается

```bash
# Проверьте наличие зависимостей
pip list | grep -E "PyQt6|pyqtgraph"

# Переустановите при необходимости
pip install --force-reinstall PyQt6 pyqtgraph
```

### Графики отображаются медленно

Включите OpenGL-акселерацию в коде:

```python
# В chart_widget.py
chart = ChartWidget(use_opengl=True)
```

### Ошибка: "Не удалось загрузить данные"

Проверьте формат файла:
- Обязательные колонки: timestamp, open, high, low, close, volume
- Timestamp должен быть в формате datetime

### Приложение зависает

Долгие операции выполняются асинхронно. Если зависание всё равно происходит:
1. Проверьте наличие ошибок в логах
2. Убедитесь, что операция выполняется в QThread
3. Перезапустите приложение
