# Changelog: Вкладка Labeling (Разметка таргетов)

## Дата: 2025-11-18

### Добавлено

#### Новая страница Labeling
- **Полноценная вкладка разметки таргетов** после вкладки Features
- Две основные вкладки:
  - **Наборы разметки**: просмотр созданных наборов разметки
  - **Задачи разметки**: конфигуратор и активные задачи

#### Методы разметки
1. **Horizon** (Горизонтный)
   - Фиксированный горизонт
   - Адаптивный горизонт (на основе ATR)
   - Настраиваемый порог для классификации

2. **Triple Barrier** (Тройной барьер)
   - Верхний барьер (Take Profit)
   - Нижний барьер (Stop Loss)
   - Временной барьер
   - Поддержка типов: процент, ATR, волатильность
   - Симметричные/асимметричные барьеры

3. **Regression** (Регрессия)
   - Future Return (будущая доходность)
   - MFE (Max Favorable Excursion)
   - MAE (Max Adverse Excursion)
   - Sharpe Ratio (скользящий)

#### Направления торговли
- Long only
- Short only
- Long + Short (двусторонняя торговля)

#### Постфильтры
- **Сглаживание**: median, mean, exponential
- **Фильтр последовательностей**: минимальная длина
- **Majority Vote**: голосование по соседним барам
- **Опасные зоны**: исключение высокой волатильности

#### Балансировка классов
- Class Weights
- Oversampling
- Undersampling
- Без балансировки

#### Дополнительные возможности
- Учёт комиссий при разметке
- Привязка к набору признаков (Feature Set)
- Применение к всем датасетам или выборочно
- Настраиваемое описание для каждой конфигурации

### API клиент

#### Новые эндпоинты (labelingAPI)
- `list()` - список наборов разметки
- `get(id)` - получить набор по ID
- `getData(id)` - получить данные разметки
- `delete(id)` - удалить набор
- `listTasks()` - список задач
- `createTasks()` - создать задачи разметки
- `getTask(id)` - получить задачу по ID
- `pauseTask(id)` - приостановить задачу
- `resumeTask(id)` - возобновить задачу
- `cancelTask(id)` - отменить задачу
- `restartTask(id)` - перезапустить задачу
- `visualize(id, chartType)` - визуализация результатов
