# Руководство по вкладке Labeling (Разметка таргетов)

## Обзор

Вкладка **Labeling** предназначена для создания разметки данных (таргетов) для последующего обучения моделей машинного обучения. Поддерживаются различные методы разметки для классификации и регрессии.

## Основные возможности

### 1. Методы разметки

#### Horizon (Горизонтный метод)
- **Фиксированный горизонт**: классификация на основе движения цены за N баров
- **Адаптивный горизонт**: динамическая настройка на основе ATR (Average True Range)
- Подходит для простых стратегий с фиксированным временным окном

#### Triple Barrier (Тройной барьер)
- Классический метод разметки с тремя барьерами:
  - **Верхний барьер** (Take Profit): целевой профит
  - **Нижний барьер** (Stop Loss): максимальный убыток
  - **Временной барьер**: максимальное время удержания позиции
- Поддержка различных типов барьеров:
  - Процентные
  - На основе ATR
  - На основе волатильности
- Симметричные и асимметричные барьеры

#### Regression (Регрессия)
- Предсказание непрерывных значений:
  - **Future Return**: будущая доходность
  - **MFE** (Max Favorable Excursion): максимальное благоприятное движение
  - **MAE** (Max Adverse Excursion): максимальное неблагоприятное движение
  - **Sharpe Ratio**: коэффициент Шарпа на скользящем окне

### 2. Направления торговли

- **Long only**: только длинные позиции
- **Short only**: только короткие позиции
- **Long + Short**: двусторонняя торговля

### 3. Постфильтры

#### Сглаживание сигналов
- Median filter
- Mean filter
- Exponential smoothing
- Удаляет шум из разметки

#### Фильтр последовательностей
- Удаление одиночных сигналов
- Минимальная длина последовательности одного класса
- Повышает качество сигналов

#### Majority Vote
- Голосование по соседним барам
- Сглаживает переходы между классами

#### Опасные зоны
- Исключение периодов высокой волатильности
- Настраиваемый порог (x σ)

### 4. Балансировка классов

Для классификационных задач доступны методы балансировки:
- **Class Weights**: взвешивание классов при обучении
- **Oversampling**: увеличение minority class
- **Undersampling**: уменьшение majority class

### 5. Учёт комиссий

Возможность учитывать комиссии брокера при расчёте минимального профита для фильтрации нерентабельных сигналов.

## Готовые пресеты

Для быстрого старта доступны готовые пресеты:

### Консервативные стратегии
- **Long консервативная 2%/1%**: классическая long стратегия с умеренным риском

### Агрессивные стратегии
- **Long агрессивная 3%/1.5%**: большие цели, больше риска

### Сбалансированные стратегии
- **Long+Short симметричная 1.5%**: двусторонняя торговля с одинаковыми барьерами

### Адаптивные стратегии
- **ATR-адаптивные барьеры**: динамические барьеры на основе ATR
- **Horizon адаптивный**: адаптивный горизонт прогнозирования

### Специализированные стратегии
- **Скальпинг 0.5%/0.3%**: быстрая торговля с малыми барьерами
- **Swing Trading 5%/2.5%**: долгосрочная торговля с большими целями

### Регрессионные пресеты
- **Regression: Future Returns**: предсказание доходности
- **Regression: MFE**: предсказание максимального благоприятного движения

## Рабочий процесс

### Шаг 1: Выбор метода разметки
1. Перейдите на вкладку **"Задачи разметки"**
2. Выберите один из трёх методов: Horizon, Triple Barrier, или Regression
3. Или нажмите **"Пресеты"** для загрузки готовой конфигурации

### Шаг 2: Настройка параметров
1. Укажите название и описание набора разметки
2. Выберите направление торговли (для классификации)
3. Настройте параметры метода:
   - Для Horizon: горизонт и порог
   - Для Triple Barrier: верхний/нижний/временной барьеры
   - Для Regression: целевую переменную и горизонт

### Шаг 3: Настройка постфильтров (опционально)
1. Нажмите **"Показать"** для раскрытия секции постфильтров
2. Включите нужные фильтры:
   - Сглаживание
   - Фильтр последовательностей
   - Majority Vote
   - Опасные зоны

### Шаг 4: Выбор датасетов
1. Выберите датасеты для разметки из списка
2. Или включите **"Для всех датасетов"** для массовой разметки
3. Опционально: привяжите набор признаков (feature set)

### Шаг 5: Запуск
1. Нажмите **"Запустить разметку"**
2. Задачи появятся в правой панели с прогрессом выполнения
3. Отслеживайте распределение классов в реальном времени

### Шаг 6: Просмотр результатов
1. Перейдите на вкладку **"Наборы разметки"**
2. Просмотрите созданные наборы разметки
3. Изучите распределение классов
4. Используйте наборы для обучения моделей

## Рекомендации

### Для внутридневной торговли (Intraday)
- Используйте Triple Barrier с малыми барьерами (0.5-1.5%)
- Короткий временной барьер (5-15 баров)
- Включите фильтр опасных зон
- Учитывайте комиссии

### Для позиционной торговли (Position)
- Triple Barrier с большими барьерами (3-5%)
- Длинный временной барьер (30-50 баров)
- Включите сглаживание и фильтр последовательностей
- Используйте балансировку классов

### Для адаптивных стратегий
- Используйте ATR-барьеры или адаптивный Horizon
- Настройте порог волатильности для опасных зон
- Включите экспоненциальное сглаживание

### Для регрессионных моделей
- Выберите Regression с подходящей целевой переменной
- Отключите балансировку классов
- Минимизируйте постфильтры для сохранения непрерывности

## Визуализация результатов

После завершения разметки доступна информация:
- **Общее количество сэмплов**
- **Распределение по классам** (для классификации)
- **Статус задачи** (queued, running, completed, failed)
- **Прогресс выполнения** в реальном времени

## Интеграция с другими модулями

Созданные наборы разметки используются:
1. **Experiments**: для обучения моделей
2. **Models**: в качестве таргетов для обучения
3. **Backtests**: для оценки качества предсказаний

## Технические детали

### Идемпотентность
Повторный запуск разметки с теми же параметрами даст идентичный результат.

### Версионирование
Каждый набор разметки сохраняется с:
- Полной конфигурацией
- Хешем исходных данных
- Метаданными (дата создания, параметры)

### Каузальность
Все методы разметки являются каузальными — не используют будущую информацию для текущих решений.

## Частые вопросы

**Q: Какой метод разметки выбрать?**
A: Для большинства задач рекомендуется Triple Barrier. Horizon подходит для простых стратегий, Regression — для предсказания конкретных величин.

**Q: Как выбрать размер барьеров?**
A: Ориентируйтесь на среднюю волатильность актива. Для стандартных акций: 1-2% для консервативных стратегий, 3-5% для агрессивных.

**Q: Нужно ли использовать постфильтры?**
A: Рекомендуется для шумных данных. Начните со сглаживания и фильтра последовательностей.

**Q: Что делать при несбалансированных классах?**
A: Используйте Class Weights как первый вариант. Если не помогает — попробуйте oversampling/undersampling.

**Q: Можно ли создать кастомную разметку?**
A: Да, используйте метод "custom" в конфигурации. Реализация через backend API.
