## Реализованные компоненты

### 1. MLflow Integration (`src/orchestration/mlflow_integration.py`)
✅ Полная обёртка над MLflow с поддержкой:
- Tracking экспериментов
- Model Registry (регистрация, версионирование, переходы между стадиями)
- Логирование параметров, метрик и артефактов
- Загрузка и выгрузка моделей
- Поиск и сравнение экспериментов
- Контекстный менеджер для удобного использования

### 2. Experiment Manager (`src/orchestration/experiment_manager.py`)
✅ Управление экспериментами:
- Создание, запуск, обновление и удаление экспериментов
- Хранение конфигураций и метаданных
- Интеграция с MLflow для трекинга
- Сравнение экспериментов
- Поиск лучшей модели по метрике
- Генерация отчетов
- Экспорт в CSV/JSON/YAML
- Очистка неудачных экспериментов

### 3. Task Scheduler (`src/orchestration/scheduler.py`)
✅ Планировщик задач с cron-поддержкой:
- Парсер cron-выражений (формат: minute hour day month day_of_week)
- Планирование обучения моделей
- Планирование бэктестов
- Планирование пайплайнов
- Включение/отключение задач
- Персистентное хранение конфигураций
- Фоновое выполнение

### 4. Task Executor (`src/orchestration/executor.py`)
✅ Исполнитель задач:
- Thread-based и process-based выполнение
- Приоритизация задач
- Отслеживание статусов (pending, running, completed, failed, cancelled)
- Пакетная отправка задач
- Отмена задач
- Ожидание завершения
- Статистика выполнения
- Context manager

### 5. Task Queue (`src/orchestration/task_queue.py`)
✅ Очередь задач (локальная и Redis):
- LocalTaskQueue - в памяти с персистентностью
- RedisTaskQueue - распределенная очередь
- TaskQueueManager - унифицированный интерфейс
- Поддержка приоритетов
- Retry логика
- Автоматический fallback к локальной очереди

### 6. Monitoring Hooks (`src/orchestration/monitoring.py`)
✅ Система хуков для мониторинга:
- LoggingHook - логирование событий
- FileHook - запись в файлы (JSON/text)
- MetricsHook - сбор метрик и счетчиков
- CallbackHook - пользовательские callback'и
- MLflowHook - интеграция с MLflow
- MonitoringHookManager - координация хуков
- Удобные методы для стандартных событий
- Фильтрация и анализ событий

## Использование

### Создание эксперимента через CLI
```bash
python -m src.interfaces.cli experiment create \
  --name "sber_lightgbm" \
  --config configs/experiments/simple_training_experiment.yaml \
  --description "Обучение LightGBM на SBER 1h" \
  --tag model=lightgbm \
  --tag ticker=SBER
```

### Запуск эксперимента
```bash
python -m src.interfaces.cli experiment run sber_lightgbm_20241115_120000
```

### Использование в коде

#### Experiment Manager
```python
from src.orchestration import ExperimentManager

manager = ExperimentManager()

# Создание эксперимента
exp_id = manager.create_experiment(
    name="my_experiment",
    config={"model": "lightgbm", "ticker": "SBER"},
    tags={"test": "true"}
)

# Запуск
manager.run_experiment(exp_id)

# Сравнение
df = manager.compare_experiments([exp_id_1, exp_id_2])

# Лучший эксперимент
best = manager.get_best_experiment("f1_score", direction="maximize")
```

#### Task Scheduler
```python
from src.orchestration import TaskScheduler

scheduler = TaskScheduler()

# Планирование задачи
scheduler.schedule_training(
    config={"model": "lightgbm"},
    schedule="0 9 * * *"  # Каждый день в 9:00
)

# Запуск планировщика
scheduler.start()
```

#### Task Executor
```python
from src.orchestration import TaskExecutor

executor = TaskExecutor(max_workers=4, execution_mode="thread")

def train_model(config):
    # Обучение модели
    return model

# Отправка задачи
task_id = executor.submit(train_model, config={"model": "xgboost"})
```

#### Monitoring
```python
from src.orchestration.monitoring import get_monitoring_manager, FileHook

manager = get_monitoring_manager()

# Добавление хуков
manager.add_hook(FileHook("logs/events.json", format="json"))

# Эмиссия событий
manager.on_training_start("model_name", {"lr": 0.001})
manager.on_training_epoch("model_name", 1, {"loss": 0.5, "accuracy": 0.85})
manager.on_training_complete("model_name", {"accuracy": 0.9}, duration=120.5)
```
