### 2. Новые команды - model_commands.py ✅

Полный набор команд для работы с моделями:

- `trading-cli model train` - обучение модели с MLflow интеграцией
- `trading-cli model list` - список обученных моделей
- `trading-cli model info` - детальная информация о модели
- `trading-cli model evaluate` - оценка модели на тестовых данных
- `trading-cli model predict` - прогнозирование с моделью
- `trading-cli model compare` - сравнение нескольких моделей

**Особенности:**
- Поддержка GPU/CPU
- Интеграция с MLflow для трекинга
- Красивый вывод с таблицами Rich
- Обработка ошибок
- Progress bars для долгих операций

### 3. Новые команды - backtest_commands.py ✅

Полный набор команд для бэктестинга:

- `trading-cli backtest run` - запуск бэктеста стратегии
- `trading-cli backtest list` - список выполненных бэктестов
- `trading-cli backtest report` - генерация подробного отчёта
- `trading-cli backtest compare` - сравнение результатов бэктестов
- `trading-cli backtest analyze` - углублённый анализ бэктеста

**Особенности:**
- Поддержка комиссий и проскальзывания
- Создание HTML/PDF отчётов
- Визуализация результатов
- Метрики: Sharpe, Sortino, Drawdown, Win Rate и др.

## Использование

### Установка

```bash
# Установка в режиме разработки
pip install -e .

# Проверка установки
trading-cli --help
trading-cli version
```

### Быстрый старт

```bash
# 1. Проверить статус системы
trading-cli quick status

# 2. Загрузить данные
trading-cli data load --ticker SBER --from 2020-01-01

# 3. Сгенерировать признаки
trading-cli features generate -c configs/features/default.yaml -d SBER_1m

# 4. Обучить модель
trading-cli model train -c configs/models/lightgbm.yaml -d train.parquet

# 5. Запустить бэктест
trading-cli backtest run -s strategy.yaml -m MODEL_ID -d test.parquet
```

### Автоматизация

```bash
# Запустить полный пайплайн
./examples/cli_examples/full_pipeline.sh SBER 1h

# Массовый бэктест
./examples/cli_examples/batch_backtest.sh MODEL_ID

# Сравнение моделей
./examples/cli_examples/model_comparison.sh train.parquet val.parquet test.parquet
```
